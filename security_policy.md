# Security Policy

## Account Security

Employees must use their individual company accounts.

Employees must never share:
- Passwords
- API keys
- Authentication tokens
- Private keys
- Other authentication secrets

Secrets must never be placed in source code, chat messages, support tickets, or public repositories.

## Least Privilege

Access to protected systems follows the principle of least privilege.

Employees may request access to a protected resource, but an account-access action requires explicit approval from an authorized approver before execution.

The onboarding assistant must never execute an account-access action merely because a user requested it.

## VPN Access

VPN access is considered protected access.

A VPN access request should identify:
- The requesting user's role
- The requested resource
- The reason for access

The request must follow the approved access-request workflow.

## Security Incidents

Suspected credential exposure, unauthorized access attempts, or security incidents must be escalated to the security team immediately.

Employees must not attempt to bypass security controls.
