# Support Escalation Guide

## First-Level Support

For laptop or account problems that block onboarding, employees should first contact the internal support channel.

The support request should include:
- A description of the problem
- Employee identifier
- Relevant non-secret error details

Employees must not include passwords, authentication tokens, API keys, or private keys in support requests.

## Escalation

If the issue remains unresolved after first-line support, it can be escalated to the IT support team.

The escalation should contain:
- The original problem description
- Troubleshooting steps already attempted
- Relevant error messages
- The impact on onboarding

## Security Incidents

Security incidents should be escalated immediately to the security team.

Examples include:
- Suspected credential exposure
- Unauthorized access attempts
- Lost authentication tokens
- Suspicious account activity

Employees must not attempt to investigate or bypass security controls on their own.

## Emergency Handling

If an issue creates an immediate security risk, stop the affected activity and contact the security team through the approved internal channel.
